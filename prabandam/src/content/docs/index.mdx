## Why this exists

This system is an open computational model:

- Root claims are explicit graph nodes.
- Relation semantics are explicit visheshanam properties.
- Inference scores are computed from equations.
- Outputs are traceable to source files and graph edges.

## Static prior + dynamic posterior

The core pattern is:

$$
\text{prior} = \sigma(\text{node}) \quad\text{from local topology}
$$

$$
\text{posterior} = \text{PPR}(\text{query},\text{seed neighborhood},\text{relation conductance})
$$

This means behavior is neither static-only nor black-box: it is deterministic data plus query-time math.
