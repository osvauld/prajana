## Count-chain two modes — graph determines which fires. Aggregation: query concept has sankhya edges from swarupa-anuvada → sum them. Example: cat is animal, 5 cats and 2 dogs → [animal, sankhya, 5] + [animal, sankhya, 2] → 7. Arithmetic: grades have asprista-sankhya with event verbs → fold with per-grade direction. Example: 10 birds, 3 flew, 2 came → 10-3+2=9. Detection: swarupa edges exist AND query concept has propagated sankhya → aggregation. Otherwise → arithmetic. No hardcoded logic.

## rashi-anuvada and swarupa-anuvada are the same abstract operation: propagate PROPERTY through RELATION. [X, vishesa, Y] + [X, sankhya, V] → [Y, sankhya, V] (rashi). [X, swarupa, Y] + [X, sankhya, V] → [Y, sankhya, V] (swarupa). This is the transitive property of identity — if X IS Y then X's attributes ARE Y's attributes. The visheshanam ring's multiplicative identity (swarupa) preserves everything it touches. Both are monotone endomorphisms in the refine fixpoint.

## Assertion-bandha copula pattern: emit-triples emits [word, copula, word] for is/are. assertion-bandha scans for: satya subject (subj-ok=true) → copula (saw-cop=true) → satya object → emit [subject, swarupa, object]. Guard: copula only fires when subject was satya (not mithya). Prevents false assertions from 'there are 5' or 'how many animals are there'. For dvandva subjects ('cats and dogs are animals'), assertion-bandha needs to accumulate subject list — currently only binds last subject before copula.
